Dataverse 자료를 공개 화면에 갱신하는 방법

공개 화면은 Dataverse를 방문자마다 실시간 조회하지 않습니다. 인증된 담당자가 동기화 작업을 실행하면 검증된 공개용 파일을 만들고, 확인 후 Sites에 게시합니다.

동기화 순서

  1. 관리 PC에서 Power Platform CLI(PAC) 인증 상태를 확인합니다.
  2. 프로젝트 루트에서 powershell -NoProfile -File poc/sync_dataverse_public.ps1를 실행합니다.
  3. 지정 환경·솔루션의 조직·자격·지표·출처 자료를 읽어 공개용 파일을 생성합니다.
  4. outputs/dataverse_public/live/manifest.json의 새 완료 시각·테이블 건수·참조 검사를 확인합니다.
  5. 로컬에서 검색·상세·통계·출처를 확인한 뒤 같은 Git 커밋을 Sites에 저장·게시합니다.
  6. 공개 사이트의 ‘마지막 동기화’ 시각과 실제 검색 결과를 다시 확인합니다.

실패하거나 기다려야 하는 경우

  • PAC 로그의 FAILED만으로 판단하지 않습니다. 완료 manifest와 READ_ONLY_EXPORT_COMPLETE 표식을 함께 확인합니다.
  • 조회·검증·빌드 중 오류가 나면 이전 공개 자료를 유지합니다. 검증되지 않은 파일은 게시하지 않습니다.
  • 동기화 성공은 공개용 파일 생성까지이며, 공개 반영은 Sites 저장·게시 후 완료입니다.
  • 현재 PC의 인증 세션을 사용하며 공개 방문자에게 Dataverse 권한을 부여하지 않습니다.

현재 범위

4개 유형의 공개 조직·자격·지표·출처 자료를 대상으로 합니다. 공지사항은 별도 경로이며 국제 자료 자동 업데이트에는 포함되지 않습니다.
