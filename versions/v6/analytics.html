조직 수 ≠ 등록 이력 수

하나의 조직이 여러 자료·연도·유형에 나타날 수 있습니다. 실제 자료의 동일기업 검토가 끝나기 전에는 조직그룹 수를 확정 고유 기업 수로 해석하지 않습니다.

자료 없음 ≠ 실적 0

미기재는 합계와 평균의 대상에서 제외합니다. 자료 확보율은 선택 조직 중 해당 연도에 지표 값이 있는 조직의 비율이며, 공시 의무 이행률이 아닙니다.

비교는 같은 기준으로

보고연도·공개일과 실적연도를 구분합니다. 종사자·조합원·참여자 수는 서로 다른 지표입니다. 정정본이 있으면 같은 조직·연도의 최신 버전만 반영합니다.

실제 데이터 연결 시 적용할 기준

조직·유형자격·지표값·출처·검토 이력을 연결해 공개 검토가 끝난 자료만 제공합니다. 단위와 실적연도, 집계방법이 확인된 지표만 분석에 사용하며, 동일기업 및 자격 유효기간 검토 전에는 복수 자격 보유 통계를 확정하지 않습니다.

Power BI의 교차 필터와 상세 분석, 담당자 앱의 자료 보완·검토 흐름으로 확장할 예정입니다. 현재 화면은 HTML에서 작동하는 시연이며 실제 업무 앱 저장이나 AI 분석은 수행하지 않습니다.
