1. 서비스 전체 개요와 빠른 시작

이 PoC는 사회연대경제 조직의 정보와 활동 자료를 한곳에서 탐색하는 서비스입니다. 검색 → 조직 발견 → 분석 → 비교 → 근거 확인으로 이어지는 경험을 제공합니다. 관심 있는 조직을 이름으로 찾을 수도 있고, 지역·유형·수치를 기준으로 찾거나 자연어로 질문할 수도 있습니다.

1.1 현재 제공하는 자료와 기능

현재 공개 자료 범위는 사회적기업·협동조합·마을기업·자활기업의 4개 유형입니다. 화면 하단에는 13개 유형의 관련 기관 링크가 있지만, 13개 유형의 자료가 모두 수록되었다는 뜻은 아닙니다.

이용 목적 시작할 화면 다음에 할 일
알고 있는 기업을 찾기 홈의 조직명 검색 상세 보기에서 주소·유형·지표·출처 확인
문장으로 조건을 말하기 AI 국민비서 해석한 조건을 확인하고 결과·근거 열기
기업의 관계와 특성 이해 기업특성이해 유형·지역·지표·출처·기업 후보 연결 선택
여러 유형에 등장하는 기업 찾기 복수 지위 탐색 연결 근거를 읽고 두 조직 비교

합계·평균·분포·연도 비교 자유 통계 분석 지표·단위·연도 지정 후 표와 출처 확인
차트를 함께 움직이며 분석 대화형 보고서 Power BI의 페이지·필터·차트 선택
숫자의 원본 확인 지표·공시 자료 조회 / 자료 출처 파일명·시트·원본 행·기준일 확인

1.2 처음 접속했다면

  1. 사이트 주소를 엽니다.
  2. 기업명이 있으면 홈의 검색창에 입력합니다. 무엇을 찾을지 설명하고 싶으면 AI 국민비서를 선택합니다.
  3. 결과의 지역·유형·조직코드를 확인합니다. 같은 이름이 여러 번 보이면 각각 다른 기록일 수 있습니다.
  4. 상세 보기 또는 원문 출처 보기로 이동해 실적연도·단위·자료 기준일을 확인합니다.
  5. 비교가 필요하면 두 조직 비교, 합계나 평균이 필요하면 자유 통계 분석으로 이어갑니다.

1.3 자료 갱신 방식

조직 검색·자유 통계·관계 탐색 등은 Dataverse에서 조회하여 공개 사이트에 동기화한 자료를 사용합니다. 캡처 당시 화면에는 2026. 9. 24. 오후 3:53:11이 동기화 시각으로 표시되었습니다. 페이지를 새로 고친다고 Dataverse의 최신 변경이 즉시 반영되는 방식은 아닙니다.

AI 국민비서는 실제 AI로 질문을 해석하지만, 결과 검색과 계산은 공개 자료에서 수행합니다. Power BI 보고서는 별도로 공개된 실제 보고서를 표시하며, 사이트의 검색 조건·자료 갱신 시점과 자동으로 연동되지 않습니다. 모바일 자료 제출용 Canvas 기능 등은 후속 개발 범위입니다.

2.3 첫 화면의 서비스 카드와 자료 현황

첫 화면의 큰 검색창은 조직명 빠른 검색입니다. 문장형 질문은 AI 국민비서를 사용합니다. 아래의 대화형 보고서·조직 찾기 등 카드와 ‘다양한 데이터 탐색’ 카드는 자주 쓰는 화면으로 이동하는 바로가기입니다.

홈의 경영공시·우리 지역 조직 서비스 카드는 현재 조직 검색 영역으로 이동합니다. 상세 지표 조회나 지역별 분포 분석이 목적이면 상단 메뉴의 지표·공시 자료 조회, 우리 지역 조직을 이용하면 목적 화면으로 바로 갈 수 있습니다.

홈에 표시된 49,036개 조직그룹, 49,270건 지표 관측은 서로 다른 단위입니다. 앞의 수는 조직 기록의 그룹 수이고, 뒤의 수는 여러 지표·연도·출처에 나타난 관측 건수입니다.

3. 조직 검색과 상세·경영공시

3.1 검색 조건과 결과 목록

이동: 기업·조직 찾기 → 조직 통합검색 또는 홈 검색창

그림 3 — ‘편안한집’을 검색하면 서로 다른 유형의 3개 조직그룹이 표시됩니다.

  1. 조직명에 이름 또는 이름 일부를 입력합니다.
  2. 필요한 경우 지역, 조직 유형을 선택합니다.
  3. 지표가 있는 조직만 보려면 지표 자료가 있는 조직만을 선택합니다.
  4. 검색을 누르고 결과 건수와 카드의 지역·유형을 확인합니다.
  5. 상세 보기를 누릅니다. 조건을 모두 해제하려면 초기화를 사용합니다.
결과의 표시 읽는 방법
경남 · 사회적기업 등 해당 조직그룹에 수록된 지역과 자료 유형
조직명 원본에서 가져온 이름. 이름만으로 동일기업을 확정하지 않음
ORG-… 조직그룹을 구분하는 코드. 동명 조직 비교 시 유용
지표 관측 N건 그 조직그룹에 연결된 지표 원문 기록 수
검색 결과 N개 조직그룹 현재 검색 조건에 맞는 그룹 수
1 / N, 이전·다음 결과 페이지 위치. 버튼이 흐리면 이동할 페이지가 없음

예시에서는 (주)편안한집이 사회적기업·자활기업·마을기업의 3개 기록으로 표시됩니다. 이것을 바로 ‘기업 3개’ 또는 ‘현재 3개 자격을 모두 가진 한 기업’으로 해석하지 않습니다. 복수 지위 탐색에서 연결 근거를 확인할 수 있습니다.

3.2 상세 창 읽기

그림 4 — 자활기업 유형의 (주)편안한집 상세 예시입니다.

상세 창은 선택한 조직의 기본 정보 → 유형 관측 이력 → 지표 원문 순서로 읽습니다.

영역 확인할 내용 의미
기본 정보 조직명, 코드, 지역·유형, 주소, 동기화 시각 어떤 조직 기록을 보고 있는지 식별
유형 관측 이력 유형·세부구분, 관측일, 번호 여러 자료와 시점에서 관측된 자격 이력
지표 원문 지표명, 실적연도, 보고연도, 값, 단위 해당 기록에 수록된 활동·공시 정보
출처 파일명, 시트명, 행 번호, 자료 기준일 값이 어디에서 왔는지 추적

캡처 예시의 참여자 수는 두 출처에서 각각 6명으로 표시됩니다. 같은 숫자가 두 번 보인다고 참여자 12명으로 단순 합산하지 않습니다. 반복 관측 여부와 기준일을 먼저 확인합니다.

지표 관측 0건은 현재 연결된 지표 자료가 없다는 뜻입니다. 매출·고용 실적이 0이라는 의미도, 공시 의무를 위반했다는 의미도 아닙니다. 창을 닫으려면 오른쪽 위 ✕를 누릅니다.

4. AI 국민비서 — 자연어 통합검색

이동: 상단 AI 국민비서 또는 기업·조직 찾기 → 자연어 통합검색

그림 5 — 이 기능은 ‘사회연대경제 정보를 찾는 AI 검색 도우미’입니다. 정부 민원 신청이나 개인별 알림을 처리하는 화면은 아닙니다.

4.1 질문하기

  1. 질문창에 지역·유형·연도·지표 등 원하는 조건을 문장으로 입력합니다.
  2. 예시 버튼을 누르면 질문이 입력됩니다. 질문하고 찾아보기 →를 눌러 실행합니다.
  3. 키보드로는 Ctrl + Enter를 사용할 수 있습니다. 질문은 최대 600자입니다.
  4. 응답이 나오면 해석한 조건 확인·수정하기를 열어 의도한 조건인지 확인합니다.
  5. 결과의 조직, 집계 근거, 그래프·공시 링크로 탐색을 이어갑니다.
질문 예시 확인할 결과
경남에 있는 사회적기업을 찾아줘 지역·유형 조건의 조직 목록
그중 하동군만 보여줘 앞 질문의 맥락을 이어서 좁힌 결과
2024년 매출액이 큰 순서로 상위 10개 보여줘 해당 지표·연도의 수치 순위와 원문 기준
3개 이상 유형에 중복되는 기업의 지역별 수를 보여줘 유형 수 조건에 맞는 중복 후보군의 지역별 집계
중복된 유형 수에 상관없이 모든 중복 기업 후보를 보여줘 전체 중복 후보군 탐색
4개 유형 모두에 중복되는 기업을 찾아줘 현재 확보한 네 유형 모두와 연결된 후보군 검색

4.2 결과와 후속 질문

10.3 같은 조직그룹의 두 연도 비교

기준연도와 비교연도를 각각 고릅니다. 위쪽의 지역·유형·지표·단위 조건은 적용하지만, 위쪽 실적연도 필터는 이 비교에 적용하지 않습니다. 양쪽 연도에 숫자가 있는 동일 조직그룹만 비교합니다.

변화율은 (비교연도 값 − 기준연도 값) ÷ 기준연도 값 × 100입니다. 기준값이 0 또는 음수이면 변화율 산출에서 제외됩니다. 서로 다른 두 연도의 공통 조직그룹이 없으면 비교할 수 없다는 안내가 나옵니다.

예시의 2023→2024 매출 비교는 공통 1,361개 조직그룹, 변화율 9.05%였습니다. 이것은 선택 자료·같은 그룹 집합·반복 관측을 포함한 원문 수치 계산입니다. 전국 기업의 공식 매출 성장률로 표현하지 않습니다.

10.4 결과 저장과 근거 확인

통계 CSV ↓로 전체 집계 결과와 지표·단위·연도·지역·유형·동기화 시각을 저장합니다. 화면에 보이는 일부 막대만 저장하는 것이 아닙니다. 주소에 반영되는 선택 조건은 주소를 복사해 공유할 수 있지만, 공유 후에도 조건을 다시 확인하는 것이 좋습니다.

사용한 원문과 출처 확인 →을 누르면 지표·지역·유형·연도를 넘겨 원문 관측 표로 이동합니다. 이 표는 집계값 자체가 아니라 계산의 바탕인 기록을 확인하는 곳입니다.

‘단위 미확인 · 원문 수치’라면 임의로 원·천원·백만원을 붙이지 마세요. ‘전체 실적연도’는 여러 연도와 미확인 연도가 섞일 수 있습니다. 반복 관측은 합산될 수 있으므로 화면의 집계 안내를 함께 남겨야 합니다.

11.2 원문 출처 보기

그림 16 — 원문 출처 보기는 해당 조직 상세로 연결됩니다. 지표 카드에서 파일명·시트·행과 기준일을 확인합니다.

  1. 표의 원문 출처 보기를 선택합니다.

12. Power BI 대화형 보고서

이동: 통계·분석 → 대화형 보고서 또는 홈의 대화형 보고서 카드

그림 17 — 별도의 실제 Power BI 공개 보고서입니다. 페이지 아래에서 1/6부터 6/6까지 이동합니다.

12.1 공통 조작

  1. 보고서가 표시될 때까지 기다립니다. 보고서 틀만 나온 상태와 차트·숫자의 로딩 완료는 다를 수 있습니다.
  2. 아래쪽 이전 페이지 / 다음 페이지로 원하는 분석 화면을 선택합니다.
  3. 보고서 안의 지역·유형·연도·지표 등의 선택 상자를 펼쳐 조건을 고릅니다.
  4. 막대나 차트의 항목을 선택하면 관련 시각화가 함께 좁혀집니다. 다중 선택은 보고서 안내에 따라 Ctrl을 사용합니다.
  5. 선택을 해제하려면 선택한 항목을 다시 누르거나 필터의 선택을 해제하고 모두 상태를 확인합니다.
  6. 크게 보려면 보고서 아래의 전체 화면 모드에서 열기 또는 위의 새 창에서 크게 보기 ↗를 사용합니다.

외부 보고서가 보이지 않으면 다시 불러오기 ↻를 누르거나 새 창 링크를 사용합니다. 여기의 필터는 Power BI 보고서 내부의 조건입니다. 홈 검색이나 자유 통계 화면에 같은 조건이 자동 적용되는 것은 아닙니다.

12.2 01 전체 현황

지역·자료 유형·세부 지역을 선택해 조직그룹, 유형·자격 관측, 지표 관측, 복수 유형 후보 쌍의 규모를 봅니다. 지역 막대와 유형 원형 차트로 구성 비중을 확인합니다. 49천과 같은 표시는 차트의 축약 표현이므로 정확한 값은 카드·표의 숫자를 확인합니다.

12.3 02 지역·유형

시도·자료 유형·시군구를 선택해 지역을 좁힙니다. 선택 조직그룹, 지표가 있는 조직, 원본 관측 행을 함께 보고, 아래의 유형별 자료 확보 현황과 지역 조직 목록을 읽습니다. 원본 관측 행은 여러 파일·시점의 기록을 포함하므로 조직 수와 같지 않습니다.

12.4 03 경영지표

지표와 단위를 하나씩 선택한 후 실적연도·유형·지역을 지정합니다. 선택지표 원문 합계, 수치 관측 수, 수치 기재율을 보고 지역별 합계와 상세 통계를 확인합니다.

‘전체연도 추이 · 연도 필터 제외’ 차트는 선택한 단일 연도와 별개로 전체 연도를 보여줍니다. 연도별 관측집단이 같지 않을 수 있으므로 추이의 증감을 동일기업 집단의 성장률로 단정하지 않습니다.

캡처의 2024년 매출 예시에서 수치 관측 1,489건 / 전체 지표 관측 1,512건이므로 수치 기재율은 약 98.5%입니다. 이는 해당 관측의 숫자 기재 비율이며 전체 기업의 공시 이행률이 아닙니다.

또한 Power BI의 전년 대비 증감률과 자유 통계의 같은 조직그룹 두 연도 비교는 계산 대상이 다를 수 있습니다. 예시의 14.4%와 9.05%처럼 다른 값이 보이면 연도·단위·필터뿐 아니라 공통 조직집합 사용 여부를 확인합니다.

12.5 04 일자리·참여

유급근로자·취약계층 관련 고용·조합원·참여자 등 관심 지표를 골라 살펴봅니다. 캡처의 기본 지표는 유급근로자 수입니다. 실적연도 미확인 기록을 포함하는지, 단위가 ‘명’인지, 반복 관측이 포함되는지를 확인합니다.

근로자·조합원·참여자는 다른 개념입니다. 지표 이름이 다르면 단위가 모두 명이어도 같은 인구집단이라고 보고 더하지 않습니다. 수치 기재율 100% 역시 현재 선택된 관측값이 숫자로 기재되었다는 의미입니다.

12.6 05 복수 지위 후보

유형 조합·탐지 근거·비교기업 A 지역을 선택합니다. 후보 쌍, 검토 대기, 검토 완료율과 아래의 후보 근거 표를 읽습니다.

이 보고서의 지역 필터는 비교기업 A 기준입니다. 공개 사이트의 복수 지위 탐색은 A 또는 B 한쪽이 해당하면 포함하므로 같은 지역명을 선택해도 건수가 다를 수 있습니다. 검토 완료율은 업무 검토 상태를 나타내며 현재 복수 자격의 유효성을 나타내는 비율이 아닙니다.

12.7 06 자료·출처

제공기관 / 원본 파일을 선택해 수록 범위와 원본 출처를 확인하는 화면입니다. 원본 파일 수, 원본 행 수, 출처 연결 수, 지표 정의 수를 함께 봅니다. 분석 결과를 설명할 때 어떤 원본 자료를 근거로 삼았는지 확인합니다. 출처 연결은 자료와 근거 사이의 연결 기록이므로 원본 행 수나 조직 수와 같지 않습니다.

현재 이 화면은 원본 파일 자체를 내려받는 기능은 제공하지 않습니다. ‘출처 목록 CSV’는 파일 목록에 관한 정보를 내려받는 기능입니다.

13.2 이용 안내

상단 처음 오셨나요? 또는 자료·이용 안내 → 처음 이용하시나요?에서 열 수 있습니다. 조직 찾기·분석·출처 확인의 흐름과 자료의 해석 범위를 먼저 읽어 보세요. 익숙하지 않은 용어는 이 설명서의 숫자와 상태를 읽는 법도 함께 참고합니다.

14. 담당자 업무·개발 현황·관련 기관

14.1 담당자 업무

대국민 공개 탐색과 자료 관리 업무는 구분됩니다. 담당자 업무 → 통합관리 업무 앱 ↗은 권한이 있는 담당자가 별도 앱에서 조직·자격·지표·출처·검토 업무를 수행하는 입구입니다.

일반 이용자는 공개 사이트에서 검색·조회·분석을 할 수 있습니다. 업무 앱이 로그인이나 접근 권한을 요구하면 담당자 계정과 권한을 확인해야 합니다. 이 설명서는 공개 사이트 이용 중심이며, 업무 앱의 자료 수정·검토 판정·공개 업무 절차는 기관의 업무 지침에 따릅니다. 접근 오류를 해결하기 위해 공개 사이트에 개인정보나 계정 비밀번호를 입력하지 않습니다.

14.2 개발 현황과 이전 화면

상단 개발 현황에서 현재 버전과 이전 화면으로 이동할 수 있습니다. 홈 본문의 개발 현황에는 구현 완료 / 다음 개발 과제 / 현재 데이터 범위와 버전별 변경 내용이 있습니다.

과거 버전은 당시 화면을 보존한 사본입니다. 오래된 가상 시연 자료·안내가 포함될 수 있으므로 현재 서비스의 데이터 범위는 최신 화면을 기준으로 확인합니다. 일부 서브페이지 하단에 과거 버전 문구가 남아 있더라도 현재 공통 메뉴와 홈의 개발 현황을 함께 확인합니다.

14.3 관련 기관 바로가기

화면 아래의 배너를 누르면 해당 기관·포털이 새 창 또는 새 탭으로 열립니다. 유형명과 기관명을 함께 확인해 원하는 곳으로 이동합니다. 외부 사이트의 운영 상태·화면·이용 조건은 해당 기관이 관리합니다.

배너는 외부 정보를 찾기 위한 안내이며, 공식 제휴나 해당 기관의 모든 데이터 확보를 뜻하지 않습니다. 현재 PoC에 확보한 자료는 4개 유형입니다.

15. 따라 해 보기

15.1 우리 지역의 조직을 찾고 원문 확인하기

  1. 기업·조직 찾기 → 우리 지역 조직을 선택합니다.
  2. 지역 경남, 자료 유형 사회적기업을 선택합니다.
  3. 조직그룹 227개, 지표 보유 106개 등 조건에 따른 요약을 확인합니다.
  4. 관심 조직 카드를 선택하거나 전체 검색 결과 →로 이동합니다.
  5. 상세 보기에서 유형 관측일·지표·파일명·시트·행을 확인합니다.

결과를 메모할 때는 ‘경남 사회적기업 227개’보다 ‘공개 동기화 자료의 경남·사회적기업 조직그룹 227개’라고 적으면 범위가 명확합니다.

15.2 같은 이름의 여러 유형 기록 비교하기

  1. 홈에서 편안한집을 검색합니다.
  2. 사회적기업·마을기업·자활기업의 서로 다른 조직코드를 확인합니다.
  3. 복수 지위 탐색에서 같은 이름을 검색합니다.
  4. 후보 카드의 연결 근거와 확인할 사항을 펼칩니다.
  5. 두 조직 나란히 비교 →에서 주소·유형 관측일·지표를 비교합니다.
  6. 기업특성이해에서 후보 관계와 출처 연결을 더 살펴봅니다.

이 과정은 자료 간 관계를 이해하기 위한 탐색입니다. 동일기업 확인이나 현재 복수 자격 확정 처리를 수행하지 않습니다.

15.3 자연어로 중복 후보군을 찾기

  1. AI 국민비서를 엽니다.
  2. 3개 이상 · 지역별 수 예시를 선택하고 질문하고 찾아보기 →를 누릅니다.
  3. ‘3개 유형 이상’으로 해석되었는지 확인합니다.
  4. 예시 결과인 85개 후보군·16개 구분과 지역 불일치 구분을 읽습니다.
  5. 지역 결과의 집계 근거와 후보군 보기를 열어 실제 기록을 확인합니다.
  6. 다른 주제로 전환할 때는 새 대화를 선택합니다.

15.4 매출의 지역별 평균을 보고 근거 남기기

  1. 자유 통계 분석에서 지표 매출액 · 1번 경영공시를 선택합니다.
  2. 실적연도 2024년, 묶어 볼 기준 지역별, 정렬·차트 집계 평균을 선택합니다.
  3. 단위가 단위 미확인 · 원문 수치임을 확인합니다.
  4. 지역별 수치 관측 수와 평균을 함께 읽습니다.
  5. 통계 CSV ↓로 집계표를 저장합니다.
  6. 사용한 원문과 출처 확인 →에서 개별 값과 근거를 확인합니다.

공유 문장 예시: “2026-09-24 동기화 자료에서 2024년 매출액 지표를 지역별로 평균 계산했다. 단위는 미확인 원문 수치이며, 숫자로 변환 가능한 관측만 사용했다.”

16.3 0·없음·미확인의 차이

  • 0: 자료에 숫자 0이 기재되었거나 해당 조건으로 세었을 때 건수가 0입니다. 어느 항목의 0인지 확인합니다.
  • 지표 관측 0건: 연결된 지표 기록이 없다는 뜻입니다. 실제 활동 실적이 0이라고 단정할 수 없습니다.
  • 자료가 없습니다: 선택 조건에 해당하는 자료가 없다는 뜻입니다. 조건을 넓히거나 다른 연도를 확인합니다.
  • 단위·연도 미확인: 원문은 있지만 그 값의 단위나 연도를 확정할 수 없는 상태입니다.
  • 비수치·결측: 수치 집계 대상에서 제외하는 기록입니다. 0으로 채우지 않습니다.

17. 모바일·키보드 이용과 자주 묻는 질문

17.1 모바일과 키보드

모바일에서는 메뉴·카드가 여러 줄로 배치됩니다. 화면을 아래로 내려 결과와 근거를 확인합니다. 폭이 넓은 표는 표 영역 안에서 좌우로 이동해 오른쪽 열까지 읽습니다. 관계 그래프의 글자가 작으면 아래의 관계 목록을 사용합니다. Power BI는 가로 방향 또는 새 창·전체 화면 보기가 편리합니다.

키보드 이용자는 Tab으로 링크·버튼·입력창을 이동하고 Enter로 실행할 수 있습니다. 첫 본문 바로가기 링크로 본문에 진입합니다. 상단 메뉴는 좌우·아래 화살표와 Esc를 지원하고, AI 질문은 Ctrl + Enter로 실행합니다. 선택 위치의 테두리를 확인하면서 이동해 주세요.

17.2 자주 묻는 질문

질문·상황 해결 방법 또는 의미
검색 결과가 없어요. 이름 일부로 검색하고 지역·유형 조건을 초기화합니다. 자료가 아직 확보되지 않은 경우도 있습니다.
같은 기업명이 여러 번 나와요. 유형·출처가 다른 조직그룹일 수 있습니다. 코드·주소·관측일을 비교하고 후보 연결을 확인합니다.
13개 유형 배너가 있는데 왜 검색은 4개 유형인가요? 배너는 외부 기관 바로가기입니다. 현재 확보한 검색 자료는 4개 유형입니다.
AI 국민비서에서 민원 신청이 되나요? 현재는 사회연대경제 공개 정보 검색 도우미입니다. 민원 신청·개인별 알림 서비스는 아닙니다.
AI가 질문을 다르게 이해했어요. 해석한 조건을 확인·수정하거나 지역·유형·지표·연도를 구체적으로 적습니다. 새 주제라면 새 대화를 누릅니다.
AI에서 4개 유형 모두를 찾았는데 결과가 없어요. 현재 자료에서 조건에 맞는 후보군이 없을 수 있습니다. ‘3개 이상’ 등 조건을 바꿔 탐색할 수 있습니다.
단위 미확인 금액에 ‘원’을 붙여도 되나요? 안 됩니다. 원문 단위를 확인하기 전에는 ‘원문 수치’로 표시합니다.
새로 고침했는데 원본 수정이 안 보여요. 공개 자료는 동기화 시점 기준입니다. 다음 동기화·게시 전에는 변경이 보이지 않을 수 있습니다.
자료를 불러오는 중이라는 문구가 계속 보여요. 네트워크를 확인하고 표시되는 다시 불러오기·다시 시도 버튼을 사용합니다. 계속 실패하면 페이지와 조건·시간을 기록해 담당자에게 전달합니다.
Power BI 틀만 있고 차트가 안 보여요. 차트 로딩을 기다린 뒤 다시 불러오기 또는 새 창에서 크게 보기를 사용합니다.
Power BI와 자유 통계 수치가 달라요. 지표·단위·연도·필터·갱신 시점·반복 관측·공통 조직집합 사용 여부를 확인합니다. 후보 지역 필터도 A 기준과 A/B 중 한쪽 기준이 다릅니다.
CSV와 화면 차트의 행 수가 달라요. 차트는 앞 일부 구분만 표시할 수 있습니다. 전체 표·다운로드 범위를 확인합니다.
원본 파일을 내려받고 싶어요. 자료 출처 목록 CSV와 원본 파일 다운로드는 다릅니다. 현재 원본 파일 자체 다운로드 기능은 제공하지 않습니다.
담당자 업무 앱이 열리지 않아요. 별도 인증·권한이 필요합니다. 기관의 앱 담당자에게 계정과 권한을 확인합니다.
그래프에서 기업을 선택하면 병합되나요? 아닙니다. 공개 그래프와 비교 화면은 탐색 기능입니다. 자료 병합이나 판정 저장을 실행하지 않습니다.
모바일에서 표 오른쪽이 안 보여요. 표 영역을 좌우로 이동하거나 화면을 가로로 돌려 봅니다.
